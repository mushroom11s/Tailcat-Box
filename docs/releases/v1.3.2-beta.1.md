## v1.3.2-beta.1

Beta 预发布 / Beta pre-release (#154). 稳定版用户不会通过应用内更新收到此版本；在设置里打开「Beta 版本」即可收到 / Stable users will not be offered this build by the in-app updater; turn on "Beta updates" in Settings to get it.

### 中文

#### ✨ 新功能
- 🖥️ 远程控制改成开关：临时控制码每次新建，长期控制码必须选择密钥，关掉再打开连接码不变
- 💾 设备分成我的设备、连接此电脑、控制过的设备，并有连接历史；只有我的设备可以信任，信任后再次连接不用点允许
- 🔌 设备卡片用系统图标，地址不再整卡可点，连接改成卡片上的按钮
- 📡 就近中继可扫描、分页，并把扫到的节点只分享给我的设备
- 📦 导出配置分成导出和导入两张卡片，并写明每一项的作用
- ⌨️ 设置里的快捷键：默认 `Ctrl+Alt+Shift+W`，按一下显示窗口，再按一下收进托盘

#### 🛠️ 修复
- 🔑 导出不再带上私钥和长期控制码，避免两台电脑导入后变成同一个地址
- 🔥 阅后即焚的说明改成悬停提示，开关开着或关着都会出现
- ❓ 各页帮助按钮默认隐藏，鼠标移到标题上才出现
- 🔁 同一把密钥不能同时在聊天、端口和长期远程里监听；停掉之后可以换地方用
- 📷 长期控制码切到临时再切回来，关闭后重新打开，二维码会重新画出来

未签名构建；macOS Gatekeeper / Windows SmartScreen 警告属正常。

### English

#### ✨ New
- 🖥️ Remote control is a switch: a temporary code is new each time, and a lasting code needs a saved key so it stays the same after you turn it off
- 💾 Devices are split into mine, computers that connected here, and computers you controlled, plus connection history. Only my devices can be trusted, and a trusted computer skips Allow next time
- 🔌 Device cards use the system icon. The address is not a button; Connect is
- 📡 Nearby relays can be scanned and paged, and shared only to my devices
- 📦 Config export is two cards, export and import, with a short note for each item
- ⌨️ Settings has one shortcut, `Ctrl+Alt+Shift+W` by default: press to show the window, press again to hide it in the tray

#### 🛠️ Fixes
- 🔑 Export no longer includes private keys or the lasting control key, so two computers do not import the same address
- 🔥 Burn-after-reading is a hover tip, shown whether the switch is on or off
- ❓ Help buttons stay hidden until the pointer is over the heading
- 🔁 One saved key cannot listen in chat, a port serve, and lasting remote at the same time. After it stops, it can be used elsewhere
- 📷 The lasting QR is drawn again after a temporary detour and another off/on

Binaries are unsigned. Gatekeeper / SmartScreen warnings are expected.
