## v1.2.7-beta.4

Beta 预发布 / Beta pre-release. 稳定版用户不会通过应用内更新收到此版本 / Stable users will not be offered this build by the in-app updater.

### 中文

#### ✨ 新功能
- 📞 通话结束后，聊天里会出现类似微信的通话记录：已接通（带时长）、已拒绝、已取消、未接听、连接失败 (#141)
- ⏰ 来电响铃 60 秒无人接听会自动结束，记为未接来电 (#141)

#### 🛠️ 修复
- 🎙️ Windows 上麦克风 / 摄像头打不开时，提示改为指向真正的开关：设置 → 隐私和安全性 → 麦克风 / 摄像头，打开访问权限和「让桌面应用访问你的麦克风 / 相机」，列表里显示的是 Microsoft Edge WebView2（不是 Tailcat Box），也提示设备可能被其他程序占用 (#140)
- 🔌 没有麦克风或摄像头时，直接提示「未检测到麦克风或摄像头」，不再误报权限问题 (#141)
- 🧹 去掉通话面板里「本地预览 / 远端媒体」的文字标注，界面更干净 (#141)
- 🧪 修复喵传恢复测试偶发失败 (#139)

未签名构建；macOS Gatekeeper / Windows SmartScreen 警告属正常。

### English

#### ✨ New
- 📞 WeChat-style call records appear in the chat when a call ends: completed (with duration), declined, cancelled, missed, or failed (#141)
- ⏰ An unanswered incoming call stops ringing after 60 seconds and is recorded as missed (#141)

#### 🛠️ Fixes
- 🎙️ On Windows, mic/camera errors now point at the real switches: Settings → Privacy & security → Microphone / Camera, the access switch and "Let desktop apps access your microphone / camera", and the entry named Microsoft Edge WebView2 (not Tailcat Box); they also mention that another app may be using the device (#140)
- 🔌 With no mic or camera attached, the app says "No microphone or camera found" instead of showing a permissions hint (#141)
- 🧹 The "Local preview / Remote media" captions are gone from the call panel (#141)
- 🧪 Fixed a flaky miao restore test (#139)

Binaries are unsigned. Gatekeeper / SmartScreen warnings are expected.
