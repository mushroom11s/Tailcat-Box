## v1.2.7-beta.2

Beta 预发布 / Beta pre-release. 稳定版用户不会通过应用内更新收到此版本 / Stable users will not be offered this build by the in-app updater.

### 中文

#### ✨ 新功能
- 🐧 新增 Linux 桌面版：托盘（StatusNotifierItem）、开机自启、更多终端支持「在终端中打开」，发布 `.tar.gz` 和 `.deb` 包；需要 glibc 2.39+（Ubuntu 24.04、Debian 13、Fedora 40）(#134)
- 📦 Linux amd64 另有 `-full.tar.gz` 完整包，内置带 WebRTC 的 WebKitGTK 2.54.1，可以语音、视频通话和共享屏幕；普通包使用系统 WebKitGTK，没有 WebRTC 时通话会给出明确提示 (#134)
- 🪟 对方共享的屏幕可以点右上角图标，在独立的系统窗口里打开，按原始分辨率显示（Windows 和 macOS）(#135)
- 📞 通话状态直接显示在通话面板里：对方、状态和时长、静音、红色挂断按钮（来电时显示接听 / 拒绝），去掉了悬浮卡片；共享屏幕时状态栏叠在画面底部 (#131)
- 🧪 设置里新增「Beta 版本」开关，默认关闭；打开后检查更新会包含预发布版本 (#136)
- 🖥️ 默认窗口改为更宽的 1152×720，1366×768 的屏幕也能完整放下 (#132)

#### 🛠️ 修复
- 🔑 使用固定密钥时，端口映射的口令在重启电脑后保持不变：实际使用的区域会存进密钥文件，开机时网络没好也不会换区域 (#137)
- ☎️ 没有对端时点通话按钮不会再展开房间详情，改为在通话面板里提示 (#135)
- 🔊 离开聊天页后通话声音照常播放，不会重复出声 (#131)

未签名构建；macOS Gatekeeper / Windows SmartScreen 警告属正常。

### English

#### ✨ New
- 🐧 Linux desktop build: tray (StatusNotifierItem), autostart, more terminals for Open in Terminal, shipped as `.tar.gz` and `.deb`; needs glibc 2.39+ (Ubuntu 24.04, Debian 13, Fedora 40) (#134)
- 📦 Linux amd64 also ships a `-full.tar.gz` package with a bundled WebKitGTK 2.54.1 built with WebRTC, so voice, video, and screen share work; the regular package uses the system WebKitGTK and shows a clear message when WebRTC is missing (#134)
- 🪟 Open a peer's shared screen in its own OS window at native resolution from the corner icon (Windows and macOS) (#135)
- 📞 Call status now sits inline in the call panel: peer, state and duration, mute, and a red hang-up button (answer / decline while ringing); the floating card is gone, and during screen share the bar overlays the bottom of the stream (#131)
- 🧪 New "Beta updates" switch in Settings, off by default; when on, update checks include pre-releases (#136)
- 🖥️ The window opens at a wider 1152×720 by default and fits a 1366×768 screen (#132)

#### 🛠️ Fixes
- 🔑 With a fixed key, the port serve address stays the same after a reboot: the region in use is saved in the key file, so a slow network at boot no longer switches regions (#137)
- ☎️ Call buttons no longer expand the room details when no peer is set; the call panel shows a hint instead (#135)
- 🔊 Call audio keeps playing on other pages without doubling up (#131)

Binaries are unsigned. Gatekeeper / SmartScreen warnings are expected.
