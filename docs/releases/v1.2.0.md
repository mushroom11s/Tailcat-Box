## v1.2.0
Feature release after 1.1.1（1.1.1 之后的功能版）。
### Highlights / 亮点
- Optional no-auth SSH on the Tunnel page: turn on **Allow SSH**, manage the allowlist, and open an in-app shell. Identity is the Tailcat node key (not system sshd / port 22). Prefer the in-app shell; Windows **Open in Terminal** may still flash-close（穿透页可选免密 SSH：打开 Allow SSH、管理白名单、应用内终端。身份是 Tailcat 节点密钥，不是系统 sshd / 22。优先用应用内终端；Windows「在终端打开」仍可能闪退）
- Mew Share shows whether the peer path is direct or relay（喵传显示路径为直连或中继）
- File sizes scale through GB / TB; in-progress download and share cards show a live transfer rate（文件大小显示到 GB / TB；下载与分享进行中显示实时速度）
- Windows portable build is a bare `.exe` (no zip). Installer filename still includes `installer`（Windows 便携版改为裸 `.exe`，不再出 zip；安装包文件名仍带 `installer`）
Binaries are unsigned. Gatekeeper / SmartScreen warnings are expected.
未签名构建；macOS Gatekeeper / Windows SmartScreen 警告属正常。
