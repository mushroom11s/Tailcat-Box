## v1.3.0

正式版 / Stable release. 汇总 v1.2.6 以来的全部改动（v1.2.7-beta.1 ~ beta.4，以及 #142、#143）/ Everything since v1.2.6 (v1.2.7-beta.1 through beta.4, plus #142 and #143).

### 中文

#### ✨ 新功能
- 🐧 新增 Linux 桌面版：托盘、开机自启、更多终端支持「在终端中打开」，提供 `.tar.gz` 和 `.deb`；需要 glibc 2.39+（Ubuntu 24.04、Debian 13、Fedora 40）(#134)
- 📦 Linux amd64 另有 `-full.tar.gz` 完整包，内置带 WebRTC 的 WebKitGTK 2.54.1，可以语音、视频通话和共享屏幕 (#134)
- 📞 语音、视频来电先响铃，由你接听或拒绝，不再直接打开麦克风；响铃 60 秒无人接听会自动结束 (#126, #141)
- 🎛️ 通话状态直接显示在通话面板里：对方、状态和时长、静音、红色挂断按钮 (#131)
- 🧾 通话结束后，聊天里会出现类似微信的通话记录：已接通（带时长）、已拒绝、已取消、未接听、连接失败 (#141)
- 🪟 对方共享的屏幕可以在独立的系统窗口里打开，按原始分辨率显示 (#125, #135)
- 🆕 打开有未读消息的房间时，第一条未读消息上方会显示「新消息」分隔线 (#143)
- 🔴 有未读消息时托盘小猫出现红点；点击托盘时小猫会铲一次猫砂 (#128)
- 🍎 macOS 菜单栏改用灰白模板猫头图标，跟随浅色和深色模式 (#129)
- 🎙️ 语音消息气泡改成微信样式，按住录音时显示波形 (#122)
- 🔌 端口服务可以为每个端口单独设置随应用启动自动开始 (#123)
- 🔑 新建密钥默认命名为 Tailcat-日期-随机串 (#124)
- 🧪 设置里新增「Beta 版本」开关，默认关闭；打开后检查更新会包含预发布版本 (#136)
- 🖥️ 默认窗口改为更宽的 1152×720，1366×768 的屏幕也能完整放下 (#132)

#### 🛠️ 修复
- 🔑 使用固定密钥时，端口映射的口令在重启电脑后保持不变 (#137)
- 🔁 端口映射停止后可以再次启动 (#138)
- ☎️ 离开聊天页后语音、视频和共享屏幕不再断开，声音照常播放 (#127, #131)
- 🎙️ Windows 上麦克风 / 摄像头打不开时，提示指向真正的系统开关（列表里显示为 Microsoft Edge WebView2）；没有设备时提示「未检测到麦克风或摄像头」(#140, #141)
- 📐 新房间页面在 1152×720 窗口下可以滚动，「连接」按钮不再被截掉 (#142)
- 💻 Windows 上 SSH「在终端中打开」不会再让应用闪退 (#130)
- ⏳ 阅后即焚倒计时移到气泡外面，样式更淡 (#122)

未签名构建；macOS Gatekeeper / Windows SmartScreen 警告属正常。

### English

#### ✨ New
- 🐧 Linux desktop build: tray, autostart, more terminals for Open in Terminal, shipped as `.tar.gz` and `.deb`; needs glibc 2.39+ (Ubuntu 24.04, Debian 13, Fedora 40) (#134)
- 📦 Linux amd64 also ships a `-full.tar.gz` with a bundled WebKitGTK 2.54.1 built with WebRTC, so voice, video, and screen share work (#134)
- 📞 Incoming voice and video calls ring and wait for you to answer or decline instead of opening the mic right away; unanswered calls stop after 60 seconds (#126, #141)
- 🎛️ Call status sits inline in the call panel: peer, state and duration, mute, and a red hang-up button (#131)
- 🧾 WeChat-style call records appear in the chat when a call ends: completed (with duration), declined, cancelled, missed, or failed (#141)
- 🪟 Open a peer's shared screen in its own OS window at native resolution (#125, #135)
- 🆕 A "New messages" divider marks the first unread message when you open a room (#143)
- 🔴 The tray cat shows a red dot for unread messages, and scoops its litter box when you click the tray (#128)
- 🍎 macOS menu bar uses a gray/white template cat head that follows light and dark mode (#129)
- 🎙️ WeChat-style voice bubbles with a live waveform while recording (#122)
- 🔌 Port serve can auto-start on app launch, set per port (#123)
- 🔑 New keys get a default name like Tailcat-YYYYMMDD-xxxxxx (#124)
- 🧪 New "Beta updates" switch in Settings, off by default; when on, update checks include pre-releases (#136)
- 🖥️ The window opens at a wider 1152×720 by default and fits a 1366×768 screen (#132)

#### 🛠️ Fixes
- 🔑 With a fixed key, the port serve address stays the same after a reboot (#137)
- 🔁 A port serve can be started again after you stop it (#138)
- ☎️ Voice, video, and screen share stay connected, with audio playing, when you leave the chat page (#127, #131)
- 🎙️ On Windows, mic/camera errors point at the real system switches (the app is listed as Microsoft Edge WebView2); with no device attached the app says "No microphone or camera found" (#140, #141)
- 📐 The new-room page scrolls in the 1152×720 window, so the Connect button is no longer cut off (#142)
- 💻 SSH "Open in Terminal" no longer crashes the app on Windows (#130)
- ⏳ The burn-after-reading countdown sits outside the bubble with a lighter style (#122)

Binaries are unsigned. Gatekeeper / SmartScreen warnings are expected.
