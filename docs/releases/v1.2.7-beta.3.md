## v1.2.7-beta.3

Beta 预发布 / Beta pre-release. 稳定版用户不会通过应用内更新收到此版本 / Stable users will not be offered this build by the in-app updater.

### 中文

#### 🛠️ 修复
- 🔁 端口映射停止后可以再次启动：之前停止后再点「启动」会被当成仍在运行而没有反应，现在停止时会清掉旧的关联，临时密钥和固定密钥都能正常重新启动 (#138)

📦 安装包和 v1.2.7-beta.2 一样：Windows、macOS、Linux（`.tar.gz` / `.deb`，amd64 另有内置 WebRTC 的 `-full.tar.gz` 完整包）。

未签名构建；macOS Gatekeeper / Windows SmartScreen 警告属正常。

### English

#### 🛠️ Fixes
- 🔁 A port serve can be started again after you stop it: before, Start after Stop did nothing because the mapping still looked like it was running. Stop now clears the stale link, and restarting works with both ephemeral and fixed keys (#138)

📦 Same packages as v1.2.7-beta.2: Windows, macOS, and Linux (`.tar.gz` / `.deb`, plus the amd64 `-full.tar.gz` with bundled WebRTC).

Binaries are unsigned. Gatekeeper / SmartScreen warnings are expected.
