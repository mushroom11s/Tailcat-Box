## v1.3.1-beta.2

Beta 预发布 / Beta pre-release. 稳定版用户不会通过应用内更新收到此版本；在设置里打开「Beta 版本」即可收到 / Stable users will not be offered this build by the in-app updater; turn on "Beta updates" in Settings to get it.

### 中文

#### 🐛 修复
- 👥 喵传支持多人同时下载：改为先到先服务的排队，每个接收方都能拿到文件，不会再被后来者顶掉而一直「排队中」(#147)
- 📊 每个接收方单独显示进度和速度，换人时进度不再从满格跳回 0，速度不再混在一起算 (#147)
- 🔒 修复给新接收方发排队通知时可能把文件数据发错对象的问题 (#147)

#### ✨ 改进
- 🗂️ 默认只显示一个接收方，其余收在「展开其余 N 个」里，可随时收起 (#147)

未签名构建；macOS Gatekeeper / Windows SmartScreen 警告属正常。

### English

#### 🐛 Fixes
- 👥 喵传 now serves multiple downloaders: a first-come, first-served queue makes sure every receiver gets the file instead of being bumped and stuck on "Queued" (#147)
- 📊 Each receiver has its own progress and speed; progress no longer jumps from full back to 0 when switching receivers, and speeds are no longer mixed together (#147)
- 🔒 Fixed a case where a queue notice to a new receiver could interleave with file data sent to someone else (#147)

#### ✨ Improvements
- 🗂️ Only one receiver is shown by default; the rest are under "Show N more" and can be collapsed again (#147)

Binaries are unsigned. Gatekeeper / SmartScreen warnings are expected.
