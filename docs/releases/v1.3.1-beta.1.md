## v1.3.1-beta.1

Beta 预发布 / Beta pre-release. 稳定版用户不会通过应用内更新收到此版本；在设置里打开「Beta 版本」即可收到 / Stable users will not be offered this build by the in-app updater; turn on "Beta updates" in Settings to get it.

### 中文

#### ✨ 改进
- 🚀 Windows 安装完成页新增「运行 Tailcat Box」选项（默认勾选），装完直接打开 (#144)
- 📁 Windows 升级安装会自动沿用上次的安装位置，不会再装到默认目录变成两份 (#144)
- 🎨 macOS 菜单栏换成彩色应用图标，和 Linux 一致；未读红点和铲猫砂动画照旧 (#146)
- 📖 README 重写为面向使用者的中英文介绍，加入使用场景；详细说明移到 `docs/usage` (#145)

未签名构建；macOS Gatekeeper / Windows SmartScreen 警告属正常。

### English

#### ✨ Improvements
- 🚀 The Windows installer's finish page has a "Run Tailcat Box" checkbox (on by default) so the app opens right after install (#144)
- 📁 Upgrading on Windows installs into your existing install folder instead of the default one, so you no longer end up with two copies (#144)
- 🎨 The macOS menu bar now shows the color app logo, matching Linux; the unread red dot and litter-scoop animation still work (#146)
- 📖 Rewritten README in English and Chinese with use cases; detailed docs moved to `docs/usage` (#145)

Binaries are unsigned. Gatekeeper / SmartScreen warnings are expected.
