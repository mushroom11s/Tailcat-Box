## v1.3.1

正式版 / Stable release. 汇总 v1.3.0 以来的全部改动（v1.3.1-beta.1 ~ beta.4）/ Everything since v1.3.0 (v1.3.1-beta.1 through beta.4).

### 中文

#### ✨ 新功能
- 🚀 喵传同一份分享最多 10 人同时下载，第 11 人起排队，按先来后到开始 (#148)
- 📊 喵传按接收方分别显示进度和速度，默认只显示一个，其余可展开 (#147)
- 🍎 macOS 菜单栏改用彩色应用 logo (#146)
- 🖱️ macOS 菜单栏左键打开应用，右键弹出菜单，和 Windows 托盘一致 (#151)
- ⌨️ macOS 常用快捷键：Cmd+Q 退出、Cmd+H 隐藏、Cmd+W 关闭窗口（托盘保留）、Cmd+M 最小化，编辑菜单 Cmd+C/V/X/A/Z 可用 (#152)
- 💿 Windows 安装器：安装完成后可直接运行，升级时沿用上次的安装目录 (#144)

#### 🛠️ 修复
- 🔀 喵传多人同时下载时不再互相顶掉、进度不再跳回 0、数据不会发错人 (#147)
- ❌ macOS 上 Cmd+Q 现在会真正退出应用 (#152)

#### 📚 文档
- 📝 README 重写为产品介绍，按使用场景说明，详细用法移到 docs/usage (#145)
- 📸 README 新增聊天、视频通话、共享屏幕截图 (#149)
- 🏆 README 加上 Product Hunt 徽章 (#150)

未签名构建；macOS Gatekeeper / Windows SmartScreen 警告属正常。

### English

#### ✨ New
- 🚀 喵传 serves up to 10 downloaders of one share at once; the 11th onward queue first-come, first-served (#148)
- 📊 喵传 shows progress and speed per receiver; one row by default, the rest expand (#147)
- 🍎 macOS menu bar shows the color app logo (#146)
- 🖱️ macOS menu bar: left-click opens the app, right-click shows the menu, matching the Windows tray (#151)
- ⌨️ macOS shortcuts: Cmd+Q quits, Cmd+H hides, Cmd+W closes the window (tray stays), Cmd+M minimizes; Edit menu Cmd+C/V/X/A/Z work (#152)
- 💿 Windows installer can launch the app on finish and reuses the previous install folder (#144)

#### 🛠️ Fixes
- 🔀 Concurrent 喵传 downloads no longer bump each other, reset progress to 0, or send data to the wrong receiver (#147)
- ❌ Cmd+Q on macOS now actually quits the app (#152)

#### 📚 Docs
- 📝 README rewritten as a product introduction built around use cases; details moved to docs/usage (#145)
- 📸 README adds chat, video call, and screen share screenshots (#149)
- 🏆 README shows a Product Hunt badge (#150)

Binaries are unsigned. Gatekeeper / SmartScreen warnings are expected.
