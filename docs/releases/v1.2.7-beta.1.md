## v1.2.7-beta.1

Beta 预发布 / Beta pre-release. 稳定版用户不会通过应用内更新收到此版本 / Stable users will not be offered this build by the in-app updater.

### 中文

#### ✨ 新功能
- 📞 语音、视频来电会先弹出悬浮卡片，由你接听或拒绝，不再直接打开麦克风；通话中卡片改成深色悬浮样式 (#126)
- 🖥️ 对方共享的屏幕可以弹出到应用内的小窗，能放大到原始像素尺寸，也能拖动调整大小 (#125)
- 🔴 有未读消息时，托盘小猫会出现红点 (#128)
- 🐱 点击托盘（macOS 上打开菜单栏菜单）时，小猫会铲一次猫砂 (#128)
- 🍎 macOS 菜单栏改用灰白模板猫头图标，自动跟随浅色和深色模式 (#129)
- 🎙️ 语音消息气泡改成微信样式，按住录音时显示波形，松手后马上出现发送中的气泡 (#122)
- 🔌 端口服务可以为每个端口单独设置随应用启动自动开始 (#123)
- 🔑 新建密钥默认命名为 Tailcat-日期-随机串 (#124)

#### 🛠️ 修复
- ☎️ 离开聊天页后语音、视频和共享屏幕不再断开，只有自己或对方挂断才会结束 (#127)
- 💻 Windows 上 SSH「在终端中打开」不会再让应用闪退 (#130)
- ⏳ 阅后即焚倒计时移到气泡外面，样式更淡 (#122)

未签名构建；macOS Gatekeeper / Windows SmartScreen 警告属正常。

### English

#### ✨ New
- 📞 Incoming voice and video calls wait on a floating card for you to answer or decline instead of opening the mic right away; the in-call card has a new dark floating look (#126)
- 🖥️ Pop a peer's shared screen out into an in-app window that can grow to native pixel size or keep a size you drag (#125)
- 🔴 The tray cat shows a red dot when you have unread messages (#128)
- 🐱 Clicking the tray (or opening the menu-bar menu on macOS) makes the cat scoop its litter box (#128)
- 🍎 macOS menu bar now uses a gray/white template cat head that follows light and dark mode (#129)
- 🎙️ WeChat-style voice bubbles, a live waveform while holding to record, and an instant "sending" bubble on release (#122)
- 🔌 Port serve can auto-start on app launch, set per port (#123)
- 🔑 New keys get a default name like Tailcat-YYYYMMDD-xxxxxx (#124)

#### 🛠️ Fixes
- ☎️ Voice, video, and screen share stay connected when you leave the chat page; they end only when you or the peer hangs up (#127)
- 💻 SSH "Open in Terminal" no longer crashes the app on Windows (#130)
- ⏳ The burn-after-reading countdown sits outside the bubble with a lighter style (#122)

Binaries are unsigned. Gatekeeper / SmartScreen warnings are expected.
